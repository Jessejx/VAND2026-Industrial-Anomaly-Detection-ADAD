# ADAD for VAND2026 Industrial Track

This repository provides the official implementation of **ADAD** for the **VAND2026 Industrial Track**.

ADAD is designed as a unified industrial anomaly detection framework under the official competition protocol. The entire pipeline, including model inference, image preprocessing, anomaly map generation, post-processing, and threshold selection, is implemented in a category-agnostic and competition-compliant manner.

## Overview

The goal of this repository is to provide a reproducible and regulation-compliant solution for the VAND2026 Industrial Track.

Instead of relying on category-specific manual tuning, ADAD follows a unified design for all categories. The same model architecture, preprocessing strategy, post-processing pipeline, and threshold selection rule are applied across different industrial object categories.

The repository supports:

- Unified model inference for all categories
- Competition-compliant preprocessing
- Category-agnostic anomaly map generation
- Unified post-processing strategy
- Validation-based threshold selection
- Official-format submission file generation

## Key Features

### Unified Model Design

ADAD uses a unified model configuration for all industrial categories. The model is not manually adjusted for individual categories during inference, ensuring that the evaluation follows the competition requirements.

### Competition-Compliant Preprocessing

All input images are processed using a consistent preprocessing pipeline. The preprocessing settings are shared across categories and are designed to avoid category-specific heuristic adjustment.

### Unified Post-processing

The anomaly maps generated by the model are further processed using a general post-processing strategy. The same post-processing rule is applied to all categories and test splits.

### Validation-Based Threshold Selection

For binary segmentation results, the threshold is selected based on the official validation setting. The threshold is estimated from validation data rather than test labels, avoiding information leakage from the test set.

### Official Submission Format

The testing script generates anomaly maps and optional thresholded segmentation masks following the required submission structure of the VAND2026 Industrial Track.

## Environment Setup

Please first install PyTorch according to your CUDA version, and then install the required packages:

```bash
pip install -r requirements.txt
```

## Dataset

The dataset root path can be specified in the configuration file or overwritten from the command line.

A typical dataset structure is expected as follows:

```text
dataset_root/
  category_name/
    train/
    validation/
    test_private/
    test_private_mixed/
```

The validation split is used for threshold estimation. Test labels are not used during threshold selection.

## Training

A typical training command is:

```bash
python train.py \
  --config configs/default.yaml \
  --data_root /path/to/dataset \
  --save_dir checkpoints/adad \
  --gpu_id 0
```

The training process saves model checkpoints to the specified directory.

## Evaluation

The evaluation script computes anomaly maps and evaluates the segmentation performance using the threshold selected from the validation set:

```bash
python evaluate.py \
  --config configs/default.yaml \
  --checkpoint checkpoints/adad/latest.pth \
  --data_root /path/to/dataset \
  --gpu_id 0
```

The evaluation protocol follows the validation-based threshold selection setting and does not use test labels for threshold tuning.

## Test and Submission Generation

To generate continuous anomaly maps for official submission:

```bash
python test.py \
  --config configs/default.yaml \
  --checkpoint checkpoints/adad/latest.pth \
  --data_root /path/to/dataset \
  --output_dir outputs/adad_submit \
  --save_tiff \
  --no_save_thresholded \
  --gpu_id 0
```

To additionally generate thresholded binary segmentation masks:

```bash
python test.py \
  --config configs/default.yaml \
  --checkpoint checkpoints/adad/latest.pth \
  --data_root /path/to/dataset \
  --output_dir outputs/adad_submit \
  --save_tiff \
  --save_thresholded \
  --gpu_id 0
```

When thresholded masks are enabled, the threshold is estimated from the validation data by default.

## Output Format

The generated submission files are saved in the official-style directory structure:

```text
outputs/adad_submit/
  anomaly_images/
    category_name/test_private/*.tiff
    category_name/test_private_mixed/*.tiff
  anomaly_images_thresholded/
    category_name/test_private/*.png
    category_name/test_private_mixed/*.png
```

The continuous anomaly maps are saved as `.tiff` files. The optional binary segmentation masks are saved as `.png` files.

## Notes

Datasets, model checkpoints, and generated submission files are not included in this repository due to size and license restrictions.

This repository is intended to provide a clean and reproducible implementation of ADAD under the official VAND2026 Industrial Track setting.
